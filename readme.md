# 🗺️ Interactive-map-UDB

Sitio web interactivo desarrollado para representar un mapa de la Universidad Don Bosco (UDB), permitiendo visualizar de forma organizada diferentes espacios y elementos de la institución.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3

## ✨ Características

- Diseño web estructurado
- HTML5 y CSS3
- Imágenes en formato SVG
- Representación visual de espacios mediante un mapa
- Organización de archivos
