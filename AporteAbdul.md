# Aporte Abdul
me encargué en el desarrollo de la estructura principal de la página web usando HTML5, así como de la implementación y organización de los estilos visuales en CSS3.

## 🧱 1. Desarrollo de la estructura HTML

Se desarrolló el archivo index.html, estableciendo la estructura y organización principal del sitio web.

Entre los elementos implementados se encuentran:

- Encabezado principal con la navegación del sitio.
- Barra de navegación con las diferentes secciones del proyecto.
- Sección de búsqueda de lugares dentro del campus.
- Filtros por categorías.
- Lista de lugares destacados.
- Área principal destinada a la representación del mapa.
- Representación de edificios, servicios y puntos de interés.
- Controles de acercamiento y alejamiento del mapa.
- Sección con información detallada del lugar seleccionado.
- Secciones de instrucciones y accesibilidad.
- Pie de página con información del proyecto.

También se utilizaron elementos semánticos de HTML5 como header, nav, main, section, article y footer para organizar correctamente el contenido.

## 🎨 2. Desarrollo de estilos CSS

Se desarrolló el archivo estilos.css para definir la apariencia visual y distribución de los diferentes elementos de la página.

Entre los aspectos implementados se encuentran:

- Definición de colores y estilos.
- Diseño de la barra de navegación.
- Estilos para botones y controles.
- Diseño visual de los edificios y elementos del mapa.
- Diseño de los marcadores de ubicación.
- Estilos para la leyenda del mapa.
- Diseño de las tarjetas de información.
- Efectos visuales para elementos interactivos.
- Uso de Flexbox y CSS Grid para la distribución de los elementos.
- Diseño responsive mediante Media Queries.
- Adaptación de la interfaz para dispositivos móviles.
  
## 🧩 3. Integración de Bootstrap

Se integró Bootstrap 5.3.8 para facilitar la construcción de la interfaz y su adaptación a diferentes tamaños de pantalla.

Se utilizaron clases y componentes de Bootstrap para elementos como:

- Sistema de columnas y filas.
- Barra de navegación responsive.
- Botones.
- Formularios.
- Contenedores.
- Menú de navegación adaptable a dispositivos móviles.
